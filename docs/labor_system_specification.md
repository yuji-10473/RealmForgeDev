# 労働システム 仕様書 (Labor System)

## 1. 概要
本システムは、プレイヤーが特定のイベント（仕事や奉仕活動）を通じて報酬を得る際、相応の体力を消耗する仕組みを定義します。

## 2. 定義と判定
- **トリガーとなるタグ**: `"労働力"`
- **判定タイミング**: イベント内の `reward`（報酬）タイプのノードに到達した瞬間。

## 3. 消費ロジック
労働タグが付与されたイベントにおいて報酬を受け取る際、以下のコストが発生します。

### 3.1. HP消費の計算
- **計算式**: `HP消費量 = floor(reward.amount / 10)`
- **注意**: 労働によるHP消費はそのまま **経験値(XP)** として蓄積されます。

### 3.2. 空腹度消費の計算
- **計算式**: `空腹度消費量 = floor(reward.amount / 20)`

### 3.3. 経験値(XP)への換算
労働によって消費されたHPは、[レベルシステム](level_system_specification.md)に基づき、プレイヤーの経験値として加算されます。
- **例**: 300K の報酬を得て 30HP 消費した場合、30XP を獲得します。

## 4. UI/UX 表示
- 労働による消耗が発生した場合、赤い警告トーストでフィードバックを与えます。
- レベルアップに必要な経験値が貯まった場合、労働終了直後にレベルアップ通知が表示されます。
