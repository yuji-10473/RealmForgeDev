# 労働システム 仕様書 (Labor System)

## 1. 概要
本システムは、プレイヤーが特定のイベント（仕事や奉仕活動）を通じて報酬を得る際、相応の体力を消耗する仕組みを定義します。これは「労働」による疲労をゲームメカニクスとして表現したものです。

## 2. 定義と判定
イベントが「労働」であるかどうかは、`eventFlows` データ内の `tags` フィールドによって判定されます。

- **トリガーとなるタグ**: `"労働力"`
- **判定タイミング**: イベント内の `reward`（報酬）タイプのノードに到達した瞬間。

## 3. 消費ロジック
労働タグが付与されたイベントにおいて報酬を受け取る際、以下のコストが発生します。

### 3.1. HP消費の計算
- **消費量**: 獲得するゴールド（`amount`）の **1/10**。
- **計算式**: `HP消費量 = floor(reward.amount / 10)`
- **例**: 300K の報酬を得る場合、30HPを消費します。

### 3.2. 実行制限と結果
- 報酬受け取り時にHPが計算された消費量分だけ減算されます。
- 現在のHPが消費量以下の数値になる場合でも、報酬は受け取れますが、HPは 0 になります。
- HP消費時には「体力を消耗した」という通知が表示されます。

## 4. データ構造例 (eventFlows)
```json
{
  "id": "quest_woodcutting",
  "title": "薪割りのお手伝い",
  "tags": ["労働力"],
  "nodes": [
    {
      "id": "node_1",
      "type": "start",
      "content": "薪割りを手伝ってくれるかい？",
      "nextStepId": "node_reward"
    },
    {
      "id": "node_reward",
      "type": "reward",
      "content": "助かったよ。これはわずかだがお礼だ。",
      "reward": {
        "amount": 200
      },
      "nextStepId": "node_end"
    },
    {
      "id": "node_end",
      "type": "end",
      "content": "また頼むよ。"
    }
  ]
}
```
※ 上記の例では、`node_reward` 到達時に 200K を獲得し、同時に 20HP を消費します。

## 5. UI/UX 表示
- 労働によるHP減少が発生した場合、赤い警告トースト（通知）で「労働により HP が XX 減少しました」と表示し、プレイヤーにフィードバックを与えます。
