# 建設（工事中）システム 仕様書 (Construction System)

## 1. 概要
本システムは、マップ上の特定のオブジェクトを「工事中」の状態とし、プレイヤーが一定のゴールド（K）を支払うことでその機能を解放（完成）できる仕組みを定義します。

## 2. 定義と判定
オブジェクトが「工事中」であるかどうかは、マップデータの `eventId` 属性によって判定されます。

### 2.1. 識別フォーマット
- **eventId**: `construction:[必要コスト]:[完成後のイベントID]`
- **例**: `construction:5000:shop_blacksmith`
    - 5000 K を支払うことで完成。完成後は `shop_blacksmith`（鍛冶屋ショップ）として機能する。

## 3. ロジック
### 3.1. 未完成状態
- **ビジュアル**: 半透明表示、または「工事中」を示すアイコンをオーバーレイ表示。
- **インタラクション**: 
    - 「ここは工事中です。完成させるには [必要コスト] K の寄付が必要です。寄付しますか？」というダイアログを表示。
- **制限**: 本来の機能（ショップ、遷移、イベント等）は実行されません。

### 3.2. 完成（解放）処理
- **条件**: プレイヤーの `gold` ≧ `必要コスト`
- **処理**:
    1. プレイヤーの `gold` から `必要コスト` を減算。
    2. インスタンスID（PlacedObject の `id`）をセーブデータの `unlockedObjectIds` に追加。
    3. その場でオブジェクトが「完成」状態に切り替わり、本来のイベントが実行可能になる。

## 4. データ構造
### 4.1. Firestore (playtestSaves/{userId})
`unlockedObjectIds` フィールドに、完成させたオブジェクトの固有 ID（インスタンスID）を配列で保持します。
```json
{
  "unlockedObjectIds": ["obj_instance_12345", "obj_instance_67890"]
}
```

## 5. UI/UX 表示
- **確認ダイアログ**: 資金投入前に、現在の所持金と必要額を対比して表示。
- **完成演出**: 資金を投入した瞬間にエフェクト（キラキラ等）を表示し、オブジェクトの透明度を 100% に戻す。
- **トースト通知**: 「[オブジェクト名] が完成しました！新しい機能が利用可能です。」を表示。

## 6. 今後の拡張予定
- **段階的建設**: 複数回に分けて資金を投入する（例：合計 10000K だが、1000K ずつ寄付できる）。
- **材料投入**: ゴールドだけでなく、特定のアイテム（木材、石材など）を納品することで完成させる。
- **必要レベル**: 特定のレベル以上に達していないと建設を開始できない制限。
