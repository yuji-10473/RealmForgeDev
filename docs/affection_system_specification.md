# 好感度システム 仕様書 (Affection System)

## 1. 概要
本システムは、プレイヤーと村人（NPC）との絆を数値化した「好感度」の管理および獲得ロジックを定義します。好感度はゲームの進行状況や、特定のキャラクターとの親密度を表現するために使用されます。

## 2. 獲得ロジック
好感度は、特定の村人が依頼主となっているイベントをクリアし、報酬（ゴールド）を受け取ることで上昇します。

### 2.1. 判定条件
好感度が上昇するためには、実行される `eventFlows` データが以下の条件を満たしている必要があります。
- **依頼主の特定**: `villagerId` フィールドに、対象となる村人の ID が設定されていること。
- **報酬の発生**: `reward`（報酬）タイプのノードに到達し、かつ `amount`（ゴールド）が設定されていること。

### 2.2. 計算式
獲得する好感度ポイントは、受け取った報酬額（K）と等しくなります。
- **計算式**: `好感度上昇量 = 報酬額 (reward.amount)`
- **例**: 村人 A からの依頼で 300K の報酬を得た場合、村人 A の好感度が 300 ポイント上昇します。

## 3. データ構造
獲得した好感度は、各ユーザーのセーブデータに保存されます。

### 3.1. Firestore (playtestSaves/{userId})
`affection` フィールドに、村人 ID をキーとしたオブジェクト形式で格納されます。
```json
{
  "affection": {
    "villager_elder": 500,
    "villager_smith": 300
  }
}
```

### 3.2. イベントデータ (eventFlows)
好感度上昇をトリガーするイベントの構造例：
```json
{
  "id": "quest_delivery",
  "title": "手紙の配達",
  "villagerId": "villager_elder",
  "villagerName": "長老",
  "nodes": [
    {
      "id": "node_reward",
      "type": "reward",
      "content": "届けてくれてありがとう。礼だ。",
      "reward": {
        "amount": 150
      }
    }
  ]
}
```

## 4. UI/UX 表示
### 4.1. 獲得時の通知
好感度が上昇した際、画面上に「好感度アップ！ [村人名]との絆が深まった。」というトースト通知が表示されます。

### 4.2. ゲームメニュー（人物名鑑）
ゲーム内のメニューから「人物」タブを選択することで、これまでに会った村人との現在の好感度を確認できます。
- **ポイント**: 現在の累計好感度ポイント。
- **レベル**: 好感度 100 ポイントにつき レベル 1 と換算して表示されます。
- **ゲージ**: 次のレベル（100ポイントごと）までの進捗が表示されます。

## 5. 拡張性（今後の予定）
- **会話の変化**: 好感度レベルに応じて、村人のセリフや反応が変化する機能。
- **プレゼント**: アイテムを渡すことで好感度を上げる機能。
- **イベント解放**: 特定の好感度以上に達することで発生する専用クエスト。
