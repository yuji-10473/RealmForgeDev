# サバイバルシステム 仕様書 (HP & 空腹度)

## 1. 概要
本システムは、プレイテスト中におけるプレイヤーの状態管理（HPおよび空腹度）を定義します。探索、アイテム獲得、および特定のイベント（労働）にはコストが伴い、獲得したリソースを消費することで状態を維持・回復します。

## 2. パラメータの定義
- **HP (Health Points)**: プレイヤーの生命力。収集アクションの実行や「労働」イベントでの活動に必要。
- **空腹度 (Hunger)**: プレイヤーの満腹状態。アイテム使用の制限に関わる。

## 3. 消費ロジック
特定のアクションを実行する際、以下のコストが発生します。

### 3.1. 収集ポイント (Collection Points) での消費
収集ポイント（キラキラした場所や特定のオブジェクト）を調べてアイテムを獲得するたびに、以下の値を消費します。
- **HP消費量**: 10
- **空腹度消費量**: 5

### 3.2. 労働イベント (Labor) での消費
`"労働力"` タグが設定されたイベントで報酬を受け取る際、報酬額に応じて体力を消耗します。
- **HP消費量**: 獲得ゴールド（`amount`）の 1/10
- 詳細は [労働システム 仕様書](labor_system_specification.md) を参照。

### 3.3. 実行制限
以下の条件を満たさない場合、収集アクションは実行できません。
- 現在のHPが収集消費量（10）未満の場合、収集アクションは拒否され「体力が足りません」という警告が表示されます。
- ※労働イベントによるHP消費は、報酬受け取り時に発生するため事前の制限はありませんが、結果としてHPが0になる可能性があります。

## 4. 回復ロジック
インベントリからアイテムや料理を使用することで、HPと空腹度を回復できます。

### 4.1. 回復方法
1. ゲームメニュー（サイドバーまたはメニューアイコン）を開く。
2. 「所持アイテム」タブから使用したいアイテムを選択。
3. 「使用する」ボタンをクリック。

### 4.2. 回復量
各アイテムまたは料理の `recoveryAmount` フィールドの値を、回復量として扱います。
- **HP回復**: 現在値 + `recoveryAmount` (最大値まで)
- **空腹度回復**: 現在値 + `recoveryAmount` (最大値まで)

### 4.3. 使用制限
- **満腹制限**: 空腹度が最大値（100）に達している場合、または **回復後の値が最大値を超える場合** はアイテムを使用できません。「お腹がいっぱいです」という警告が表示されます。
- 空腹度が限界を超えて（100を超えて）蓄積されることはありません。

## 5. UI/UX 表示
- **HPゲージ**: 画面上部に赤色のアイコン（ハート）と共に表示。残量が20%を切ると赤く点滅します。
- **空腹度ゲージ**: HPゲージの隣にオレンジ色のアイコン（カトラリー）と共に表示。残量が20%を切るとオレンジ色に点滅します。

## 6. データ保存 (Save/Load)
現在のHPおよび空腹度の状態は、`/playtestSaves/{userId}` の Firestore ドキュメントに保存されます。
- `hp`: 数値
- `hunger`: 数値
- `maxHp`: 数値 (デフォルト100)
- `maxHunger`: 数値 (デフォルト100)
