# Google AdSense 活用ガイド (Implementation Guide)

## 1. 概要
本プラットフォーム（RealmForge）における Google AdSense の効果的な活用方法と、ポリシーを遵守しながら収益化を最大化するための戦略を定義します。単に広告を貼るだけでなく、ユーザー体験を損なわずに「コンテンツ」として成立させる手法を解説します。

## 2. 推奨される配置場所

### 2.1. ランディングページ（ログイン前）
- **戦略**: 訪問者が最初に目にする場所です。
- **実装のコツ**: ログインボタンの直下ではなく、ページの最下部（フッター付近）や、「RealmForgeでできること」の紹介セクションの合間に「ディスプレイ広告」を配置します。
- **注意点**: AdSenseの審査を通過させるためには、このページに一定量（最低1000文字程度）のテキストコンテンツ（RPG制作のメリットや機能詳細など）が必要です。

### 2.2. アセット・ライブラリ画面
- **戦略**: ユーザーがアセットを探すために長く滞在するページです。
- **配置**: アセット一覧のグリッドの合間、あるいはサイドバーの空きスペースに配置します。
- **メリット**: 「画像を探す」という視覚的な作業中のため、インフィード広告が自然に馴染みます。

### 2.3. H5 Games Ads (ゲーム向け広告)
- **戦略**: プレイテスト中にインタラクティブな広告を表示します。
- **内容**: マップ遷移時、大きなイベントの前後、あるいはゲームのロード中に「インタースティシャル広告」や「報酬型広告」を導入します。
- **メリット**: 通常のバナー広告よりも視認性が高く、クリック率（CTR）や単価（eCPM）が大幅に向上する傾向があります。

## 3. 収益化を最大化するコンテンツ対策

AdSenseは「価値ある独自のコンテンツ」を重視します。以下のページを追加・充実させることで、広告の表示率と単価を向上させることができます。

1.  **作品ショーケース**: ユーザーが作成したマップのスクリーンショットや、イベントの構成案を紹介するページ。
2.  **パッチノート**: バージョンアップ（Ver 0.1.15など）の詳細な変更点を記した開発ログ。
3.  **FAQ・フォーラム**: 制作上の悩みや解決策をまとめたナレッジベース。

## 4. ポリシー遵守とリスク管理

アカウント停止を防ぐために以下のルールを厳守してください。

- **広告ラベルの制限（重要）**: 広告ユニットの直上に表示するラベルは、**「広告」**または**「スポンサーリンク」**（あるいはその英語表記）のみを使用してください。**「Google広告」や「Google提供」といった独自の文言を使用することは、AdSenseのポリシーで禁止されており、アカウント停止のリスクがあります。**
- **自動表示されるブランド**: 広告が実際に配信されると、Googleのシステムによって「Ads by Google」などのロゴが広告内に自動的に表示されます。そのため、パブリッシャー側で独自にGoogleの名前を冠したラベルを付ける必要はありません。
- **ボタンとの距離**: 「保存」「削除」「ログイン」などの重要なボタンから、広告ユニットを最低でも 20px 以上（推奨は 50px）離してください。
- **誘導の禁止**: ユーザーに対して「広告をクリックして応援してください」といった文言を記載することは禁止されています。

## 5. 推奨される広告ユニットの種類

- **自動広告**: ページ構造をAIが分析し、最適な位置に自動で挿入します。手間がかからず、最も安全です。
- **H5 Games Ads**: プレイテスト環境に特化したインタラクティブ広告。
- **マルチプレックス広告**: ページ末尾に、記事のレコメンドのように表示される広告です。

## 6. まとめ
ログイン画面に単体で配置するよりも、**「RPG制作のノウハウ」を解説するテキストページを充実させ、その中に広告を組み込む形**が、最も審査に通りやすく、かつ収益も安定する王道の手法です。
