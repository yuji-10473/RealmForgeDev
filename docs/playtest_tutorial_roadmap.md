# プレイテスト・チュートリアル実装ロードマップ (Tutorial Roadmap)

## 1. 概要
RealmForge のプレイテストには、サバイバル、経済、物語といった多くのシステムが統合されています。新規プレイヤー（テスター）が迷うことなくこれらの機能を体験できるよう、段階的なチュートリアルを導入するための計画を定義します。

---

## 2. 実装フェーズ

### Phase 1: 基本操作と導入 (The Basics)
プレイヤーが最初に降り立つマップで、最も基本的な「動かし方」を学びます。
*   **学習項目**: 
    *   移動（WASDキー / マップクリック）。
    *   近接判定とアクション（キラキラボタン / スペースキー）。
    *   「看板」や「NPC」との最初の会話。
*   **実装案**: ゲーム開始時に専用の「導入イベント」を自動実行し、最初の目的地（例：長老の家）を提示する。

### Phase 2: サバイバルと自己管理 (Survival Loop)
キャラクターの状態（ステータス）と、世界への干渉方法を学びます。
*   **学習項目**:
    *   収集ポイント（草むら、木など）での素材獲得。
    *   HPと空腹度の消費リスク。
    *   メニュー（Sheet）を開き、手に入れた「パン」などのアイテムを使用して回復する。
*   **実装案**: 収集ポイントを調べた直後に「お腹が空いたらメニューから食事をしよう」というガイドを表示。

### Phase 3: 経済サイクルと発展 (Economy & Progression)
ただ生き延びるだけでなく、村の経済に貢献し、報酬を得る流れを学びます。
*   **学習項目**:
    *   ショップ（道具屋）での売買。
    *   料理屋への「納品（補充）」。
    *   布団で「休息」し、日付（Day）を進めて売上精算を確認する。
    *   経験値（XP）の獲得とレベルアップによる恩恵。
*   **実装案**: 最初の納品を行った際、「明日になれば報酬が手に入る」ことを強調する。

### Phase 4: 世界観と人間関係 (Narrative & Bonds)
ゲームの深みである「物語」と「絆」のシステムを体験します。
*   **学習項目**:
    *   集会所（Meeting Place）での複数イベントの選択。
    *   報酬獲得による「好感度（Affection）」の上昇。
    *   アーカイブ（物語の記憶）からのカットシーン再再生。
*   **実装案**: 好感度が一定以上に達した際、メニューの「人物名鑑」を確認するよう促す。

## 3. ガイドの配信手法 (Delivery Methods)

チュートリアルをどのようにプレイヤーに届けるかの手法案です。

| 手法 | メリット | デメリット |
| :--- | :--- | :--- |
| **チュートリアルNPC** | 世界観に馴染み、没入感を削がない。 | 話しかけないと情報が得られない。 |
| **ポップアップ通知** | 確実に読ませることができる。 | プレイのテンポを阻害する可能性がある。 |
| **クエスト形式** | 「次になにをすべきか」が明確になる。 | 実装（フラグ管理）がやや複雑。 |
| **ヘルプメニュー** | いつでも見返せる。 | 能動的に開く必要がある。 |

## 4. 短期的なタスクリスト (To-Do)

- [ ] **導入イベントの作成**: `eventFlows` に「初めてのプレイヤーへの挨拶」を追加。
- [ ] **ガイドUIの追加**: 特定のアクション（初収集など）をトリガーにした一時的なヒント表示機能。
- [ ] **初期所持品の調整**: 最初からパンを1つ持たせ、「食べる体験」を促す。
- [ ] **看板オブジェクトの設置**: 各システムの近くに説明用の看板（PlacedObject）を配置。

---

## 5. 評価指標 (KPI)
チュートリアルの成功を以下の数値で評価します。
*   **初日完了率**: ゲーム開始から「最初の休息（売上精算）」まで到達したユーザーの割合。
*   **アイテム使用率**: アイテムを一度も使わずにHP切れになるユーザーの減少。
*   **平均プレイ時間**: システムを理解することで継続プレイ時間が延びているか。
