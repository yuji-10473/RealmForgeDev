# モバイル対応（レスポンシブ・タッチ操作）ロードマップ

## 1. 縦型のUI
*   **概要**: スマートフォンの縦持ち（Portrait）操作に特化した、上下に情報が整理されたレイアウトを構築します。
*   **主なタスク**:
    - ステータスバー（HP/K/Day）、メッセージウィンドウ、操作用ボタンの縦長画面への再配置。
    - 縦長画面におけるマップ描画領域のアスペクト比最適化とスケーリング。
    - 片手操作を意識したボタン配置とサイズ調整。

## 2. UIの選択と変更可能オプション
*   **概要**: ユーザーが自分のプレイスタイルや端末の種類に合わせて、インターフェースを柔軟に調整できる機能を提供します。
*   **主なタスク**:
    - 「縦型固定」「横型固定」「自動回転」を選択できる表示設定の追加。
    - 仮想ジョイスティックの配置変更（左利き/右利き対応）および透明度・感度の設定。
    - ショートカットボタンのカスタマイズ（よく使うアイテムや機能を登録）。

## 3. Mobile Agent に自動UI割当
*   **概要**: ユーザーがアクセスしたデバイス（User Agent）を自動的に判別し、最適なUI（Mobile Agentモード）を即座に割り当てます。
*   **主なタスク**:
    - ブラウザの User Agent もしくは画面解像度に基づいた初期UIの自動選別ロジックの実装。
    - PC環境からのアクセスであっても、開発者オプションとしてモバイルUI（シミュレーション）を選択可能にする。
    - モバイル端末検知時、フルスクリーンモードへの移行を促すガイドの自動表示。
