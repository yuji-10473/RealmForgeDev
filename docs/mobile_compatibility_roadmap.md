# モバイル対応（レスポンシブ・タッチ操作）ロードマップ

## 1. 概要
現在の PC 中心（キーボード操作）のプレイテスト環境を、スマートフォンやタブレットでも快適に遊べるようにするための段階的な改修計画を定義します。

---

## 2. 実装フェーズ

### Phase 1: レアウトと UI のレスポンシブ化
*   **目標**: 画面サイズに応じて UI 要素が重ならず、適切なサイズで表示されること。
*   **タスク**:
    - [ ] ステータスバー（HP/K/Day）の折りたたみ、またはアイコン化。
    - [ ] サイドバーメニューのモバイル用ハンバーガーメニュー化（完了済み）。
    - [ ] インタラクションボタン（キラキラ）の押しやすい配置（右下など）。
    - [ ] 全画面表示（Fullscreen API）のモバイル最適化。

### Phase 2: 仮想ジョイスティックの実装
*   **目標**: キーボードがなくてもキャラクターを自在に動かせること。
*   **タスク**:
    - [ ] 画面左側に透過型の仮想ジョイスティック（アナログパッド）を配置。
    - [ ] タッチ座標から移動ベクトルを計算し、`PlayTestClient` の移動ロジックと統合。
    - [ ] 画面上の任意の場所をクリックした際の「ターゲット移動」との排他制御。

### Phase 3: タッチインタラクションの洗練
*   **目標**: 会話やメニュー操作が指でスムーズに行えること。
*   **タスク**:
    - [ ] イベントダイアログの「次へ」ボタンを大きく、押しやすく調整。
    - [ ] 長押し（Long Press）によるオブジェクト情報の確認。
    - [ ] メニュー（Sheet）内のスクロール体験の向上（モーメンタムスクロール）。

### Phase 4: モバイル特有の最適化 (PWA)
*   **目標**: アプリのようにインストール可能にし、オフライン耐性を高めること。
*   **タスク**:
    - [ ] `manifest.json` の設定（ホーム画面に追加）。
    - [ ] 縦向き（Portrait）と横向き（Landscape）の切り替え警告または最適化。
    - [ ] ネットワーク不安定時のオートセーブの堅牢化。

---

## 3. 優先順位
1.  **Phase 1 & 2**: 操作不能を解消するため最優先。
2.  **Phase 3**: プレイの快適性に直結。
3.  **Phase 4**: 将来的なアプリ化に向けたステップ。
