# 日付システム 仕様書 (Day System)

## 1. 概要
本システムは、プレイテスト内での時間の経過を「日数」として管理する仕組みを定義します。世界観のリアリティを高め、長期的なサバイバル体験を提供することを目的とします。

## 2. カウントルール
- **開始日**: ゲーム開始時は「1日目」からスタートします。
- **最大日数**: 上限はなく、整数でカウントされ続けます。
- **表示形式**: UI上では「1日目」「Day 10」のように表示されます。

## 3. 日付更新のトリガー
日付は、特定の「休息アクション」を実行した瞬間にカウントアップされます。

### 3.1. 休息（布団）による経過
- **トリガー**: マップ上のオブジェクト「布団」を調べ、休息を完了したとき。
- **処理**: `現在の数値 + 1`
- **リセット**: 日付が戻ることはありません。

## 4. データ構造
### 4.1. Firestore (playtestSaves/{userId})
`day` フィールドに数値を保存します。
```json
{
  "day": 5
}
```

## 5. 今後の拡張予定
- **特定の日付限定イベント**: 「7日目のみ発生するイベント」などのフラグ管理。
- **日替わりショップ**: 日付が変わるごとにショップのラインナップが更新される機能。
- **時間帯の概念**: 昼・夕方・夜のビジュアル変化（カラーフィルター）との連動。
