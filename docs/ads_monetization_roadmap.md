# 広告収益化ロードマップ & 指標 (Monetization Roadmap)

## 1. 収益化の3段階フェーズ

本プラットフォームの成長に合わせた、段階的な収益化プランを定義します。

### フェーズ1：準備と審査 (現在)
- **目標**: AdSense アカウントの有効化と初期審査の通過。
- **アクション**:
    - ランディングページへの解説テキスト（1000文字以上）の追加。
    - 利用規約およびプライバシーポリシーの整備。
    - 標準的なディスプレイ広告枠の設置（プレースホルダー）。
- **主要指標 (KPI)**: ページビュー数 (PV), 審査通過の有無。

### フェーズ2：実装と検証 (PV 1万/月〜)
- **目標**: ユーザー体験を損なわない最適な広告配置の特定。
- **アクション**:
    - **H5 Games Ads (Game Placement API)** の導入。
    - マップ遷移時やリソース収集完了時へのインタースティシャル広告のテスト導入。
    - アセットライブラリへのインフィード広告配置。
- **主要指標 (KPI)**: クリック率 (CTR), 有効インプレッション収益 (eCPM)。

### フェーズ3：最適化とスケーリング (PV 10万/月〜)
- **目標**: 収益の最大化とリピーター維持の両立。
- **アクション**:
    - 報酬型広告 (Rewarded Ads) の導入（例：広告視聴で特定のレアアセットを1日開放）。
    - 広告ユニット別の A/B テスト実施。
    - 広告非表示オプション（サブスクリプション）の検討。
- **主要指標 (KPI)**: ユーザーあたりの平均収益 (ARPU), 広告表示後の離脱率。

---

## 2. 追跡すべき主要指標 (KPI)

収益性を正しく評価するために、以下の数値を定期的に確認します。

| 指標 | 定義 | 目標値 (目安) | 改善策 |
| :--- | :--- | :--- | :--- |
| **CTR (クリック率)** | 広告表示に対するクリックの割合 | 0.5% - 2.0% | 広告の配置場所や関連性の見直し |
| **eCPM (インプレッション単価)** | 1000回表示あたりの推定収益 | 50円 - 300円 | H5 Games Ads 等の高単価ユニットの活用 |
| **Fill Rate (広告充足率)** | 広告リクエストに対して実際に表示された割合 | 95%以上 | コンテンツの独自性を高め、広告在庫を確保 |
| **Session Duration (滞在時間)** | ユーザーが1回に滞在する平均時間 | 5分以上 | エディターの操作性向上、チュートリアルの充実 |
| **Invalid Traffic Rate (無効トラフィック)** | 自己クリック等の不正なアクセスの割合 | 1%以下 | 開発中の広告非表示設定の徹底 |

---

## 3. H5 Games Ads 導入の指標

H5 Games Ads を導入する際の「成功」の定義：
1.  **ゲーム体験の維持**: 広告表示後の「プレイテスト再開率」が 90% 以上であること。
2.  **エンゲージメント**: 報酬型広告の選択率がアクティブユーザーの 30% 以上であること。
