
# レベルシステム 仕様書 (Level & Experience System)

## 1. 概要
本システムは、プレイヤーの活動（HPの消費）を「経験」として蓄積し、レベルアップを通じてキャラクターを強化する仕組みを定義します。成長に応じて、サバイバル活動における効率が向上します。

## 2. 経験値 (XP) の獲得
本ゲームでは、プレイヤーがエネルギーを消費して活動すること自体を経験とみなします。

### 2.1. 獲得ロジック
- **判定タイミング**: あらゆるアクション（採集、労働など）によって HP が減少した瞬間。
- **獲得量**: 消費された HP の数値がそのまま経験値（XP）となります。
- **計算式**: `獲得XP = 消費HP量`
- **例**: 採集で 10HP 消費した場合、10XP を獲得します。

## 3. レベルアップ
蓄積された累計経験値が、現在のレベルに応じた「次レベルへの必要経験値（NextXP）」に達するとレベルアップします。

### 3.1. 必要経験値の計算式
レベル $Level$ から $Level + 1$ へ上がるために必要な経験値は、以下の二次関数を用いて計算されます。

$$NextXP = a \times Level^2 + b \times Level + c$$

- **デフォルト係数 (初期テスト値)**:
    - $a = 10$
    - $b = 50$
    - $c = 1000$ (初期のご要望に合わせて設定)
- **例**:
    - Lv.1 → 2: $10(1)^2 + 50(1) + 1000 = 1060$ XP
    - Lv.2 → 3: $10(2)^2 + 50(2) + 1000 = 1140$ XP

## 4. レベル補正 (レベルボーナス)
レベルが上がるごとに、プレイヤーの行動に対して **5% 刻み** のプラス補正（ボーナス）が付与されます。

### 4.1. 補正値の計算
- **計算式**: `補正倍率 = 1.0 + (Level - 1) * 0.05`
- **例**:
    - Lv.1: 1.00 (補正なし)
    - Lv.2: 1.05 (5%強化)
    - Lv.5: 1.20 (20%強化)
    - Lv.11: 1.50 (50%強化)

## 5. 補正の適用メリット
レベル補正は、主に「消費の抑制」と「回復の強化」に作用します。

### 5.1. 採集コストの軽減
採集ポイントでの活動時、補正値に応じて消費 HP が減少します。
- **計算式**: `実際の消費HP = floor(基本コスト / 補正倍率)`
- **例 (Lv.5 / 補正1.20)**: `floor(10 / 1.20) = 8` HP (20%軽減)

### 5.2. 回復効率の向上
アイテムや料理を使用した際、補正値に応じて回復量が増加します。
- **計算式**: `実際の回復量 = floor(基本回復量 * 補正倍率)`
- **例 (Lv.5 / 補正1.20)**: `floor(160 * 1.20) = 192` HP (20%増加)

## 6. UI/UX 表示
- **経験値ゲージ**: 画面上部に現在のレベルと次のレベルまでの進捗ゲージを表示します。
- **レベルアップ演出**: レベルアップ時にトースト通知で「Level Up! [新レベル] に到達。活動効率が5%向上した！」と表示します。
